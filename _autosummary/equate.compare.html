equate.compare¶

The compare stage (②): score how alike two (featurized) items are.

There are two routes (decision register / doc 00-taxonomy):

  • featurize-then-compare (featurized()) — an indexable vector metric over independent representations (what the legacy similarity_matrix does); only this route can drive an ANN/LSH index;

  • direct pairwise compare (direct()) — an opaque scorer h(a, b) -> float (edit distance, a cross-encoder/LLM); it can only re-rank a candidate set.

Pairwise comparators are (a, b) -> float callables; select one by name via the comparators registry or pass a callable. Each carries a equate.base.ComparatorMeta (polarity / bounded / is_metric / is_symmetric) so the framework adapts — never treating a non-metric as a metric, keeping directional comparators (Monge-Elkan, containment) directional until the matcher boundary (D3).

equate.compare.comparison_vector(a, b, field_comparators, *, missing=0.0)[source]¶

Return {field: comparator(a[field], b[field])} for each field comparator.

field_comparators maps a field name to a pairwise comparator; records may be mappings or objects (attribute access). A field whose value is missing (None) in either record scores missing (default 0.0) rather than being passed to the comparator — many comparators (edit distance, ratio) raise on None.

>>> from equate.compare.string import levenshtein
>>> cv = comparison_vector({'name': 'jon'}, {'name': 'john'}, {'name': levenshtein})
>>> round(cv['name'], 2)
0.75

equate.compare.fellegi_sunter(m_probs, u_probs, *, eps=1e-06)[source]¶

Fellegi-Sunter combiner (decision register D5): sum of per-field match weights.

For each field with agreement s in [0, 1], contributes s*log(m/u) + (1-s)*log((1-m)/(1-u)) — the log-likelihood-ratio “match weight”. m_probs / u_probs are the m- and u-probabilities per field (from labels or EM; the EM estimation lives in the classify stage, roadmap #8). Returns a log-odds score (higher = more likely a match). Probabilities are clamped to [eps, 1-eps] so m/u of exactly 0 or 1 can’t cause log(0) / division-by-zero.

equate.compare.polarity_sense(comparator, *, default='maximize')[source]¶

The score sense a comparator’s declared polarity implies.

A 'distance' comparator (DTW, edit distance) is minimized, a 'similarity' maximized; a comparator with no declared metadata gets default.

>>> polarity_sense(resolve_comparator('dtw'))
'minimize'
>>> polarity_sense(resolve_comparator('ratio'))
'maximize'

equate.fusion¶

Fuse aligned records field by field, weighting sources by trust, and report conflicts.

The stage after equate.align_sources() (data fusion, or “truth discovery” when the source weights are learned): for each item, each field’s candidate values are grouped into votes (values that agree), each vote weighs the summed trust of the sources behind it, and the heaviest vote wins. The value kept is the one from the most trusted source in the winning vote, and its source is recorded as the field’s provenance.

A field is a conflict when a losing vote weighs at least conflict_ratio of the winning one: trusted sources disagree (a field no source is trusted for never is). Numbers agree only when equal by default: give timing fields a tolerance, e.g. agree={'start': lambda a, b: abs(a - b) < 0.1}. A noisy, low-trust source contradicting a trusted one is expected and not reported; two trusted sources disagreeing is exactly what a person should check.

>>> from equate import align_sources
>>> sheet = [{'text': 'bonjour', 'fr': 'hello'}, {'text': 'merci', 'fr': 'thanks'}]
>>> ocr = [{'text': 'bonjour'}, {'text': 'mercl'}]
>>> audio = [{'text': 'bonjou', 'start': 0.0}, {'text': 'merci', 'start': 1.5}]
>>> al = align_sources({'sheet': sheet, 'ocr': ocr, 'audio': audio})
>>> fused = fuse(al, trust={'audio': {'text': 0.3}})
>>> [item.values for item in fused]
[{'text': 'bonjour', 'fr': 'hello', 'start': 0.0},
 {'text': 'merci', 'fr': 'thanks', 'start': 1.5}]
>>> [(c.field, c.votes[1].sources) for c in fused[1].conflicts]
[('text', ['ocr'])]

equate.fusion.fuse(groups, *, trust=None, agree=None, conflict_ratio=0.5, fields=None)[source]¶

Fuse each aligned item’s records into one, field by field.

groups is a SourceAlignment (from align_sources()) or any iterable of its SourceGroup items.

  • trust: {source: weight} or {source: {field: weight}}; anything unstated weighs DFLT_TRUST (so the default is equal trust). A weight of 0 keeps a source’s value only when no other source has the field.

  • agree: when two values of a field agree: None (default_agree()), a predicate (a, b) -> bool, or {field: predicate}.

  • conflict_ratio: a field is a conflict when a losing vote weighs at least this fraction of the winning one.

  • fields: the fields to fuse (default: every field of every record, in the order first seen).

Returns a Fusion: iterate it for FusedItem items; .conflicts and .unmatched list what a person should look at.

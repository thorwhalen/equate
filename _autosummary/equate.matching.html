equate.matching¶

The match stage (③): turn a score matrix into a correspondence.

A Matcher is a strategy over a score structure — the choice is the objective, not the algorithm (decision register D4). Select by name via the matchers registry or pass a callable (scores, *, sense) -> pairs. The optimal matcher is sparse-aware (routes a blocked matrix to the sparse LAP); soft matching (optimal transport) lives in a parallel soft_match() / harden() seam.

equate.matching.align(G1, G2, *, how='isorank', node_affinity=None, seeds=None, **config)[source]¶

Align the nodes of two graphs -> a Matching of node pairs.

how picks the quadratic matcher ('isorank' core, 'rrwm' via equate[graph-matching], or a callable); node_affinity is an optional prior (an (n1, n2) array or a (u, v) -> float callable, non-negative) and usually what makes topology-only alignment work (see isorank_scores()); seeds are known (G1 node, G2 node) anchors. Other keywords configure the matcher (e.g. extract='greedy', alpha=0.9). Graphs may be networkx graphs, {node: neighbors} mappings or adjacency matrices.

>>> star = {'hub': ['x', 'y', 'z'], 'x': ['hub'], 'y': ['hub'], 'z': ['hub']}
>>> other = {0: [3], 1: [3], 2: [3], 3: [0, 1, 2]}
>>> dict(align(star, other).labeled_pairs())['hub']
3
equate.matching.greedy_matching(scores, *, sense=None)[source]¶

Greedy 1:1: repeatedly take the best still-available (i, j), removing both.

Order-dependent and not globally optimal, but fast. Iterates stored_entries(), so for a sparse (blocked) matrix only the stored candidate cells are considered — an absent cell is never a match.

equate.matching.isorank(G1, G2, *, node_affinity=None, seeds=None, extract='optimal', label=None, **config)[source]¶

Align two graphs with IsoRank -> a Matching of node pairs.

matching.labeled_pairs() yields (G1 node, G2 node); .plan holds the full IsoRank score matrix. extract is the flat matcher that turns it into a 1:1 correspondence (any name or callable equate.matching.resolve_matcher() takes); **config goes to isorank_scores() (alpha, max_iter, tol).

>>> G1 = {'a': ['b'], 'b': ['a', 'c', 'd'], 'c': ['b'], 'd': ['b', 'e'], 'e': ['d']}
>>> G2 = {1: [2, 4], 2: [1], 3: [4], 4: [1, 3, 5], 5: [4]}  # the same graph, renamed
>>> dict(isorank(G1, G2).labeled_pairs())['b'], dict(isorank(G1, G2).labeled_pairs())['d']
(4, 1)

equate.matching.optimal_matching(scores, *, sense=None)[source]¶

Globally optimal 1:1 assignment (the linear assignment problem).

Accepts a ScoreMatrix (native) or a raw dense/sparse array with sense= (back-compat). Solves linear_sum_assignment on dense_cost() — so a sparse (blocked) matrix has its absent cells worst-cased (never preferred over a real pair) and any assignment landing on a non-candidate cell is dropped via candidate_mask(): a row with no candidate is left unmatched (a partial matching), an all-absent matrix yields no matches. Densifying the cost is a correctness stopgap; a non-densifying sparse LAP is a future optimization (scipy’s sparse solver silently drops explicitly-stored zero-score candidates, so it is not used here).

equate.matching.resolve_matcher(spec='optimal', **config)[source]¶

Resolve spec to a runner (scores_or_scorematrix, *, sense=None) -> pairs.

A registered name (or a facade how= alias like 'assign' -> 'optimal') is built via the registry; a callable is used as-is. The returned runner coerces its argument to a ScoreMatrix and then either hands that matrix to a native matcher (so it worst-cases holes through the sanctioned views) or hands a legacy raw-array matcher a hole-worst-cased dense array — so the sparse hole-worst-casing holds no matter which contract the matcher follows (D11).

Note this returns a runner, not spec itself: unlike the pre-D11 version it is no longer an identity passthrough for a callable (resolve_matcher(f) is f was true, and is not any more). The runner carries the wrapped matcher’s __name__/__doc__, and the original is recoverable via __wrapped__.

equate.matching.rrwm(G1, G2, *, node_affinity=None, seeds=None, extract='optimal', label=None, sigma=1.0, **rrwm_params)[source]¶

Align two graphs with pygmtools’ RRWM — requires equate[graph-matching].

Builds the quadratic affinity K from Gaussian edge-weight agreement (bandwidth sigma) with node_affinity on its diagonal, solves it with pygmtools.rrwm (**rrwm_params forwarded), and extracts a 1:1 correspondence with the flat extract matcher. Seeds condition the solve: every assignment contradicting one (its node paired elsewhere) is removed from K and the seed pair gets the top affinity, so the rest is aligned around it; seeds are then kept as given. Graphs with no edges and no prior fall back to a uniform node affinity. Uses the numpy backend and never changes pygmtools’ global backend.

equate.matching.soft_match(scores, *, sense=None, reg=0.1, a=None, b=None)[source]¶

Entropic optimal-transport (Sinkhorn) plan over the cost derived from scores.

Accepts a ScoreMatrix (native) or a raw array with sense=. Returns a dense transport-plan matrix whose rows/cols sum to the marginals a/b (uniform by default). Requires equate[ot] (POT). reg (entropic regularization) must be > 0 (reg=0 divides by zero inside Sinkhorn).

equate.matching.stable_matching(scores, *, sense=None)[source]¶

Gale-Shapley stable matching (optimizes stability, not total score).

See equate.util.stable_marriage_matching(). Ranks preferences by dense_cost() (absent cells worst-cased), so a sparse (blocked) cell never out-ranks a real candidate; hole-assignments are then dropped via candidate_mask().
